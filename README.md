# rock-paper-scissors
An interactive Rock Paper Scissors game built with HTML, CSS, and JavaScript. Features random computer moves, score tracking, and a modern, responsive gaming interface.
✊ Rock Paper Scissors Game

A fun and interactive Rock Paper Scissors game built using HTML, CSS, and JavaScript.

Features
🎮 Interactive gameplay
🤖 Random computer moves
🏆 User and computer score tracking
🎨 Modern gaming UI
📱 Responsive design
Technologies
HTML5
CSS3
JavaScript
How to Play

Choose Rock, Paper, or Scissors and compete against the computer. The score updates automatically whenever either player wins.
